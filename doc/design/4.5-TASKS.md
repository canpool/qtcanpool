# QtCanpool 4.5 任务规划

> 4.5 是功能升级版本（可能破坏 API），在 4.4（不破坏 API 的内部重构，已发布 4.4.2）基础上做能力增长与破坏收尾。本文档为 4.5 的权威任务分解。

## 一、版本定位与约束

- 功能升级：允许移除/改签名（K26）；引入成熟的功能性改进与超出同类的能力。
- 双支持：保留 Qt 5 / Qt 6 双支持（K30）。
- 验证腿：Qt 6.12 验证已在 4.4.2 提为门禁（K31），4.5 复用不重建。
- 进号：因可能移除/改签名 → minor；破坏项需 migration 文档（K11 / 附录 B）。
- 弃用闸门：`QX_<LIB>_DEPRECATED_SINCE` 家族保留不清理（预留机制，非死代码）。

## 三、执行序建议

1. **第一批（破坏收尾）**：A1 + A2，各配 migration 文档（J2），独立小步。
