## 零、本版定位

**一句话**：把「一套观感只覆盖半个表面」补成能画一整页，再把两个旗舰 demo 从控件陈列推到能交出去的产品。

**完备性原则（本版最高原则，高于下表其余行）**：两个库要提供**完备**的功能组件，不留需要用户自己
封装的缺口。⇒ 参考站组件面的每一条，要么本版做，要么给了**替代实现**；第三波（§二 末）已并入本版
一次做完，本版结束时两族组件面与两份参考站对齐。§七 从「明确不进」改为「**不进本版但替代方案已定**」。

三条目标落到三组：

**「替代实现」的三种语义**（本稿出现多处，执行时按此分辨，不混用）：

| 语义 | 例 | 性质 | 效果 |
| :--- | :--- | :--- | :--- |
| **自绘替代原生** | A7 `MenuFlyout` 替原生 `QMenu`；`QxPopupSurface` 替原生弹层 | **永久**——本族的正确做法 | 原生件功能无缺，但观感不受令牌体系控制：菜单面由 `QStyle` 画、配色走系统调色板，圆角 / 阴影 / hover 洗色 / 开合动效一条都插不进去，`setStyleSheet` 修补两族各一份且易碎。自绘达到**同等功能 + 家族一致观感**，是升级不是妥协（若原生观感能接受，整个库都不需要） |
| **分期替代** | A10 `DatePicker`（字段 + 宫格 flyout）先行、A14 完整 `CalendarView` 收尾；C8 只读表格页先行、B14 `Table` 真件收尾 | **先后关系**，不是永久替代——轻实现先回答「用户要完成任务」，重件是选型题（容器选型见 A11 / B14），第三波补齐 | 轻实现覆盖常见路径，判据里写明覆盖边界；完整件同版补上，本版结束时无缺口。注意 A10 的「字段 + flyout」本就是 WinUI 自己 `DatePicker` 的形态——参照站把 `DatePicker` 与 `CalendarView` 本来就做成两个控件 |
| **形态对齐** | A9 `AutoSuggestBox` 替「可编辑 ComboBox」；B17 `Autocomplete` | 参照站的**原生形态**：WinUI / MUI 里可编辑下拉的正解就是它，不是给 ComboBox 加 editable | 照抄站上形态，不发明 Qt 特有的杂交件 |

完备用判据兜底：每一处替代都要么功能同等，要么判据写明边界且完整件在同版第三波——
不存在「用了替代实现所以少一块」的缺口。

| 目标 | 落在哪 | 一句话 |
| :--- | :--- | :--- |
| 对照参考站，为两族添加新组件 | **A 组 / B 组**（三波） | 两族补齐基础件与结构件——今天 gallery 与 demo 里所有裸 Qt 控件的替换件 |
| 两个 demo 更华丽、达到产品级 | **C 组**（八笔） | 响应式三断点、三个变体页、零裸控件、图标成套、过渡与空载态、Table 替代页——每条都有判据，不靠眼感 |
| 纳入原计划属于 4.7.3 的内容 | **§一.1 第 3 条** | 4.7.2 §X 与系列候选池里标「下一个 patch」的条目，逐条对上 |

**不在本版**（§七，替代方案已定的条目）：私有类可见性工程、CI 的无 MSVC 腿、Qt5 金标坐标口径、
第三四族风格库、`PaneDisplayMode::Top`。

**兼容面**（K36 一行）：本版全部是**新增**——两族三波合计 **40 余个类**、`qxcontrols` 一个共用件、
demo 与测试改动。不改任何既有签名、不删任何 API、不改名 ⇒ **patch**，库号按 Q5 走 `+0.0.1`，
**不开 minor**（K37 不触发）。

## 二、任务分解

### A 组 · qxfluent（对照 WinUI Gallery 的组件页）

清单的取法：`qxfluent` 现有 18 件里，**命令层、反馈层、骨架层**都有了（CommandBar / ContentDialog /
NavigationView / TabView / BreadcrumbBar…），缺的是**表单层与基础件**——也就是「一整页」里出现次数
最多的那几件。

**第一波 · 基础六件：**

| 笔 | 内容 | 形态要点（取自参考站） | 判据 |
| :--- | :--- | :--- | :--- |
| **A1** | `FluentButton`（附带 `FluentDivider`） | 三档 `Kind`：`Standard` / `Accent` / `Subtle`（WinUI 的三个 `ButtonStyle`）；文本 / 图标 + 文本 / 只有图标；高 32、圆角 `Medium`；hover 用 `QxStateLayer` 洗色，按下不位移。`Divider` 一条 1 px 的线，`Inset` / `Full` 两个变体，约 25 行 | 三档各一条像素断言；图标单独时 `sizeHint` 是正方形；`setEnabled(false)` 后洗色层不出现；两个 Divider 变体的起止 x 差一个 `kIndent` |
| **A2** | `FluentCheckBox` + `FluentRadioButton`（**同笔**） | 框 20×20、圆角 `Small`、勾是描边不是字；三态含 `PartiallyChecked`；标签在右、命中区整行；`RadioButton` 同组互斥 | 三态各一条几何断言；点标签也能切换；同组两个只能选一个；`QAccessible` 报 `Checkable` / `Checked` |
| **A3** | `FluentComboBox` | 非可编辑；右侧 `ChevronDown`；展开在下方、下方没地方翻到上方、贴屏幕边内缩；列表最高 320 + 滚动；键盘 `Up/Down/Home/End/Enter/Esc` | 三个定位算例（下方 / 翻转 / 内缩）；键盘走一遍；`currentIndexChanged` 只在值真变时发 |
| **A4** | `FluentProgressBar` | 线性；`determinate` 与 `indeterminate` 两态；高 4、圆角 `Circular`；indeterminate 的动效走 `FluentMotion`（reduce-motion 下停下来，但**不消失**） | 两态各一条像素断言；`setValue` 到 100 时整条满；reduce-motion 下无 `QTimer` 在跑 |
| **A5** | `FluentToolTip` | 四向放置（`Top` / `Bottom` / `Left` / `Right`，默认 `Top`）；延迟 400 ms、停留 5 s；键盘焦点到达也显示 | 四个方向各一条几何断言；延迟期内移开不出现；焦点移走即关 |
| **A6** | `FluentTextBox` | 单行；占位文本；前置 / 后置图标位（搜索、清除）；`ClearButton`；焦点下划线用 `Accent` | 占位文字不盖住输入；清除按钮点了发 `cleared()`；`setReadOnly` / `setEnabled` 各一条 |

> ⚠️ **A6 与候选池原清单的差异**：候选池写的第六件是 `Divider`，本稿换成 `TextBox`，理由见 Q1。
> `Divider` 没被砍，只是并进 A1（它没有「形态」可讲，单独一笔是凑数）。

⚠️ 为什么 `FluentButton` 不继承 `QPushButton`：`QPushButton` 的 `sizeHint`、`styleSheet` 与
`QStyle::PE_PushButton` 三条路都在画自己的东西，继承就要一路关掉。`qxfluent` 里 **16 个控件一律
`QxControls::QxControl`**（另两个不是控件：`FluentContentDialog` 是 `QDialog`、`FluentReveal` 是
`QObject` 效果器），本版新增的类照这条走——库内形态一致，不因为「Qt 有个现成的」破例。

### B 组 · qxmaterial（对照 MUI v4 的组件页）

**第一波 · 基础六件：**

| 笔 | 内容 | 形态要点 | 判据 |
| :--- | :--- | :--- | :--- |
| **B1** | `MaterialButton` | 三变体 `Variant`：`Filled` / `Outlined` / `Text`；涟漪由 `MaterialRipple` 提供（与 `Fab` / `Chip` 同一份）；高 36、圆角 `Small`；`Filled` 无阴影、`Raised` 可选 | 三变体各一条像素断言；涟漪只在 `Filled` 与 `Outlined` 上出现；禁用态无涟漪 |
| **B2** | `MaterialCheckBox` + `MaterialRadio`（**同笔**） | 框 18×18、圆角 2；选中填 `Primary`、勾是描边；`Radio` 为圆 + 内点；涟漪在框上而非整行 | 三态各一条几何断言；`Radio` 同组互斥；涟漪中心落在框心（±1 px） |
| **B3** | `MaterialSelect` | 基于 `MaterialTextField`（`Filled` / `Outlined` 两态沿用）；下拉表面与 A3 **共用**一个 popup 件；菜单项高 48、选中项左侧留勾位 | 两态各能展开；三个定位算例同 A3；`currentIndexChanged` 语义同 A3 |
| **B4** | `MaterialProgress` | 线性；determinate / indeterminate；高 4、圆角 `Circular`；track 用 `SurfaceVariant`、条用 `Primary` | 同 A4 的两条 + 颜色取自令牌（不写死） |
| **B5** | `MaterialTooltip` | 深色小片（`InverseSurface` 底 + `InverseOnSurface` 字）、圆角 `Small`、四向；MUI 的 tooltip 无箭头，这里也不画 | 四个方向各一条；颜色是反色对；focus 也显示 |
| **B6** | `MaterialDivider` | `Full` / `Inset` / `Middle` **三**变体（MUI 有 `variant="middle"`）、1 px、`Outline` 色 | 三个变体的缩进各一条几何断言 |

**共用件（不单独成笔，落在 B3 那一笔里，提交信息 `feat(controls): ...`）**：
`QxControls::QxPopupSurface`——「带阴影的圆角表面 + 屏幕内定位 + 关外点击 + Esc」。它被 A3 / A5 / B3 / B5
**四件**消费，符合 `controls.md` §二「两族答案相同 ⇒ 下沉 `qxcontrols`」的判据。
⚠️ **不在 A3 之前抽**：按仓库的口径，一个东西**第二次出现**时才抽——A3 先内联实现，B3 开工时抽出来、
回头改 A3，理由是「第二遍是照做、不是重新设计」（`4.7.2-TASKS.md` §三 同一句）。
判据：抽完之后 A3 的四个用例一条不改仍绿（这是「纯搬移」的证据）。

### A 组 · 第二波（结构件提前取一批）

第二波的取法：原排后续版本的那批结构件里，**能替代实现的全取**——菜单表面是下拉与建议的枢轴，
先立它；PasswordBox / AutoSuggestBox 站在第一波的 TextBox 上；CalendarView 太重，**替代实现**是
「字段 + 宫格 flyout」，把它本来要回答的事（选一个日期 / 选一个时刻）答了。

| 笔 | 内容 | 形态要点（取自 WinUI Gallery） | 判据 |
| :--- | :--- | :--- | :--- |
| **A7** | `FluentMenuFlyout` | 自绘菜单表面（`QxPopupSurface` 的第三个消费者）：条目 / 分隔 / 小节标题、图标位、快捷键列、勾选态；**替代** `FluentDropDownButton` 现在开的原生 `QMenu`，`FluentCommandBar` 的下拉同笔切过去 | 打开 / 条目 hover / 勾选各一条像素断言；键盘 `Up/Down/Enter/Esc`；`DropDownButton` 换面后旧用例一条不改仍绿 |
| **A8** | `FluentPasswordBox` | 站在 A6 `FluentTextBox` 上：密码回显字符、揭示按钮（按住显示）、占位文本 | 揭示前后回显各一条断言；占位文本不盖字符；禁用态 |
| **A9** | `FluentAutoSuggestBox` | 输入即建议：文本变化驱动建议列表（模型无关，`QStringList` 起步），`Enter` / 点击补全、`Esc` 关闭——**替代**「可编辑 ComboBox」的完整形态 | 建议随文本刷新；键盘三键走查；无建议时不出 popup |
| **A10** | `FluentDatePicker` + `FluentTimePicker`（**同笔**） | **CalendarView 的替代实现**：字段 + 月份宫格 flyout（A7 表面），月导航、今日高亮、禁用日期；TimePicker = 时 / 分两列 flyout | 选日回填字段；月导航与今日断言；键盘可达；reduce-motion 下 flyout 无动画但不缺失 |

## 四、验证判据（V 组）

**每笔的通用七条**（A / B 组每件都要过）：

1. **两腿构建**（qt6 + qt5）——新增类没有平台分支，仍两腿编译（版本宏与命名空间差异只有另一条腿看得见）。
2. **本类用例全绿**（qt6 一条腿跑套件；新增类挂进 `tests/qxfluent|qxmaterial/auto/`，并在 `main.cpp` 的
   `TEST_ADD` 链上）。
3. **三态 + 禁用 + 焦点**：每种状态至少一条几何或像素断言（不是「能跑起来」）。
4. **令牌零硬编码**：颜色 / 字 / 圆角 / 时长全部取自本族令牌，源码里除了令牌自己不许出现 `#RRGGBB`。
5. **`sizeHint` / `minimumSizeHint`**：`sizeHint() == minimumSizeHint()` 或两者差在预期内，各一条断言。
6. **`QAccessible`**：`role` / `name` / `state` 三样对（沿用 `QxControlAccessible`）。
7. **格式与编码门禁**：`clang-format --style=file`（21.1.8）+ `scripts/check-encoding.py` 干净。

**分组追加**：

| 组 | 追加判据 |
| :--- | :--- |
| A / B | 每波落完后跑一次 **gallery 整页渲染**（`galleryRenders`），确认没有一件把页撑破 |
| C1 / C2 | `tst_demoscreenshot` 的三断点用例（**确定性断言，不做金标**）：八次进程启动，全部绿 |
| C3 / C5 / C7 | 两 demo 静默启动各一次；页面能开、能切、不崩 |
| C4 | `check-demo-widgets.py`：预算逐笔递减，本笔结束时为 0（往后再多一个就红） |
| C6 | reduce-motion 开关下过渡时长为 0 的断言；连续切换 20 次不崩 |
