# QtCanpool 4.7 系列台账（4.7.x · 系列层）

> 这一层是**系列层**，和 `4.7.0-TASKS.md` 是两回事：
>
> - **本文件**管的是「整个 4.7.x 都成立」的东西——进度指针、候选池、指路。它**在系列期间
>   持续增长，但只增长指针与结论**，不长执行流水。
> - **[`4.7.0-TASKS.md`](./4.7.0-TASKS.md)** 管的是那一个 patch 的分解、执行记录与结算，
>   **发版那笔封版**，此后新工作开 `4.7.1-TASKS.md`，不回写。
>
> 目录制（从 4.7 起，作者 2026-10-22 定）的规则见 `doc/pages/contributing.md` 的「台账」一行；
> 「4.7.x 什么时候收尾、开 4.8」的判据见 `doc/ROADMAP-3.x.md` 的 **K37**。
>
> 4.7 的定位、硬约束、评审决策（§七）与勘察依据（§八）**仍写在 4.7.0 的台账里**——4.7 是
> 目录制落地时正在推进的版本，把那些节搬走会让 §交叉引用全部失效；本层用指路的方式引用它们，
> 而不是复制一份（复制就会有两处要同时改）。**4.8 起新建的系列台账则直接承载这些内容。**

## 二、候选池（下一个 patch 从这取材）

记的是「已勘察、可开工」的条。4.7.0 未尽事宜也回到这里，**不回写 4.7.0 的文件**。
本段也是 **K37 判据读的那一段**：逐条问「能否在不改签名、不删 API、不改名的前提下落地」
（2026-10-22 代裁后口径：**行为变更允许落 patch**，依据 `4.7.1-TASKS.md` §六裁决记 Q11；
权威文件的改口列在该稿 S10 清单）。

- **C6 滚动追加池剩余**（`4.7.0-TASKS.md` §二 C6，标 `stretch`，故不属于 4.7.0）
  **已排入 4.7.1 B 组**：`NumberBox`（输入层）· `DropDownButton` / `ToggleSplitButton`
  （命令层，抽成独立类；`CommandBar` 暂不动，去重笔排 4.7.2，见下条）· `ContentDialog`（反馈层）。
- **D5 滚动追加池剩余**（同口径，`stretch`）**已排入 4.7.1 B 组**：`TextField`
  （浮动标签 + 填充/描边两态）· `Dialog`（basic / full-screen 两档）。
- ⚠️ 两池里 **骨架层四件已在 4.7.0 落地**（`NavigationView` / `TabView` / `NavigationRail` /
  `TopAppBar`），不再算候选。
- **内部重构：五个千行文件拆分**（勘察依据 `4.7.0-TASKS.md` §八）。作者 2026-10-22 裁定
  **patch 里可以重构**——按 K36 表「内部重构，公开面不变 ⇒ patch +1」，它不动接口契约
  （不改签名、不删 API、不改名），**不是 minor 的触发器**，所以留在本系列做 patch。
  顺序按体量：`ribbonbar.cpp` **2385** → `dockcontainer.cpp` 1674 → `dockwidget.cpp` 1339 →
  `dockwindow.cpp` 1326 → `dockpanel.cpp` 1275（2026-10-22 实测；初稿的 2353 是收尾前旧数）。
  判据：**纯搬移**（不改行为、不改公开面）、双腿构建全绿、截图金标零像素差。
  **已排入 4.7.1 A 组**（作者 2026-10-22 定：4.7.0 就此定稿，重构整体留给 4.7.1，
  不拆分到两个 patch）；执行分解与判据见 `4.7.1-TASKS.md`。
  同批可搭的两件内部工程（`4.7.0-TASKS.md` §八 裁定「4.7 不加」，理由见该处）：
  `RibbonButtonPrivate::calcIconAndTextRect()` 与 `DockContainerPrivate::adjustSplitterSizesOnInsertion()`
  的可见性——两者都要库与测试两端按 `QT_BUILD_INTERNAL` 构建，属独立工程，与拆分同批更划算。
- **`FluentCommandBar` 改复用新抽出的下拉 / 分体按钮**（Q7 裁定的连带项）：4.7.1 B 组把
  `DropDownButton` / `ToggleSplitButton` 抽成独立类时 `CommandBar` **暂不动**（保「既有源码
  零修改」）；去重（删 CommandBar 的私有副本、改调新类）是**单独一笔**，有行为风险、要单独验，
  且那笔自己要重验 `controlgallery.png` 金标——`CommandBar` 在 gallery 截图里。**排 4.7.2**。
- **旗舰 demo 重构：fluentdemo / materialdemo**（**已排入 4.7.1 D 组**，拆法与判据见
  `4.7.1-TASKS.md` §二 D 组 / §四 D 套）：两份参考站——fluentdemo 对
  [WinUI Gallery](https://github.com/microsoft/WinUI-Gallery)，materialdemo 对
  [MUI 模板页](https://v4.mui.com/zh/getting-started/templates/)。两条硬要求：
  ① **基于 qxwindow 定制标题栏**（`WindowAgentWidget` + `setTitleBar` + `setSystemButton`，
  范本 `demos/qxwindow`）；② 不引第三方（图表位 `QPainter` 自绘、markdown 用
  `QTextBrowser` 渲染富文本）。边界：只用**已有**控件搭页面，**不补组件缺口**
  （见下两条，4.7.2 起逐件补）。
- **qxmaterial 组件缺口**（对照 MUI v4 控件清单；**未排版本，4.7.2 起逐件补、每件独立成笔**）：
  Menu · List · Table · Stepper · Timeline · Tooltip · Avatar · ExpansionPanel ·
  BottomNavigation · Drawer · Autocomplete · Select · SpeedDial · Divider · 基础 Button。
- **qxfluent 组件缺口**（对照 WinUI 控件清单，同上；**未排版本**）：TextBox 族
  （TextBox / PasswordBox / AutoSuggestBox）· Flyout · MenuFlyout / MenuBar ·
  ItemsView / ListView / GridView · CalendarView / DatePicker / TimePicker · Pivot ·
  ScrollView · PersonPicture · ColorPicker · SwipeControl · ToolTip · CheckBox /
  RadioButton · SplitButton。
- **新平台族风格库 ×2**（调研 [`4.7-STYLES.md`](./4.7-STYLES.md)，**已排 4.7.2**）：作者
  2026-10-22 定「**4.7-STYLES.md 不进入 4.7.1，在 4.7.2 引入两个风格**」——够格两家
  **Cupertino（Apple HIG）** 与 **HarmonyOS（鸿蒙）**，Adwaita / Ant Design 一族 /
  One UI 等不够格（理由见该稿）。硬约束：**作者环境（Windows）可验证** ⇒ 纯自绘
  （`QPainter` / `QStyle` / QSS / 动画），不做窗口材质类与窗口类（作者没有 macOS 环境，
  平台材质效果半边不可验）。连带面：gallery 两页 → 四页、`controls.md` 三选项 → 五、
  版本表多两列（库 10 → 12）——全是文档与 demo 接线，不动既有库源码。
- ~~**金标比对工具修复**（4.7.1 R1 执行中发现）~~ **已在 4.7.1 S8 结清**：两个症状都不是比较
  逻辑的毛病——「失败且无任何输出」是不带 `-o <file>,txt` 时 MinGW GUI 子系统吞掉 stdout；
  「4.7.0 上也失败」是 `dockdemo.png` 陈旧（4.6/4.7 令牌化改了分隔线取色，而那张图自 `e8db4bd9`
  起没再生成）。三张金标重基线后 ④ / ⑩ 恢复可用，仍 opt-in（默认不跑、CI 不判）。
- **Qt5 金标腿的坐标口径（新，S8 记下的弱点）**：Qt5 侧捕获的是**设备像素**（DPR 100/96 ⇒ 图比
  逻辑大 4.17%），而 `--inspect` 给出的矩形是**逻辑像素** ⇒ `fresh.copy(control.rect)` 每处偏 4%。
  两侧偏得一样，仍能抓到「切主题后没重上色」，但切的不是控制件真正的那些像素。改它要重定判据，
  且很可能立刻暴露 Qt5 侧的真差异——**未排版本**，动之前先想清楚「偏得一样」是否已经够用。
