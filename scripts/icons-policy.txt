# The icon policy: how every managed icon is classified, and - for the ones that
# are tinted - which of the two tinting mechanisms consumes it.
#
#     <kind> <path> [<consumer>]
#
#   kind      tinted (follows the theme) | multicolor (exempt) | plain (fixed)
#   path      a directory (applies to every svg under it) or a single file,
#             relative to the root of the repository
#   consumer  alpha (qxribbon recolours the rasterised alpha) or dock (qxdock
#             replaces colour literals in the svg text); alpha by default, and
#             only meaningful for tinted
#
# A file entry wins over the directory it lives in, and the longest directory
# prefix wins over a shorter one, so demos/qxapp/common/icons/svg can be tinted
# while a brand mark beside it is plain.
#
# See doc/pages/icons.md for what the kinds mean and why the colours matter.

# The dock buttons: qxdock replaces colour literals in these files, so every
# colour they paint has to be one the replacement table covers.
tinted      src/libs/qxdock/res/images              dock

# Exceptions inside that directory. DockIconProvider only builds icons from its
# own spec table; these seven are reached by url() out of a dock style sheet, or
# by nothing at all, so their colours are never rewritten and none is asserted
# on them. They are listed one by one rather than left unclassified because an
# unclassified icon is reported, and "forgotten" is not what any of them is.
plain       src/libs/qxdock/res/images/maximize-button-focused.svg
plain       src/libs/qxdock/res/images/restore-button-focused.svg
plain       src/libs/qxdock/res/images/maximize-button.svg
plain       src/libs/qxdock/res/images/restore-button.svg
plain       src/libs/qxdock/res/images/pin-button.svg
plain       src/libs/qxdock/res/images/pin-button-big.svg
plain       src/libs/qxdock/res/images/vs-pin-button_45.svg

# Single-colour glyphs taken from one upstream set, written in the canonical
# colour so that QxTheme::themedIcon() can repaint them from the palette. One
# copy of them serves the ribbon, fluent and material demos - the ribbon and
# material demos paint each glyph from the palette every time they need it, the
# fluent demo keeps the picture and makes it again when the theme moves. See
# demos/qxapp/common/icons/LICENSE.txt.
tinted      demos/qxapp/common/icons/svg

# The project mark the demo paints in the title bar and the about dialog. Brand
# art, not a glyph: its colours are the point, so nothing rewrites them.
plain       demos/qxapp/ribbondemo/res/logo.svg
plain       demos/qxapp/ribbondemo/res/logo64.svg

# Legacy icon sets. They are classified rather than left out - an unclassified
